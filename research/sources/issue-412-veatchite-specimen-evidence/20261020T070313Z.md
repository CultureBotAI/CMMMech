### Model and printed-table differences

In CIF3, lines 162–165, `Sr1/Ca1` share one coordinate/ADP set, and `Sr2/Ca2` share the other. This directly establishes the deposited model's site pairing. It supports reading the first repeated `Ca2` in the printed coupled-occupancy note as the component paired with Sr1, but is not an authoritative corrected version of that note.

CIF3's Ca occupancy tokens have no encoded uncertainty. Their site sums with Sr are 1.0047 and 0.9987 as written, so exact unity constraints must not be reconstructed from rounded tokens. The file records two restraints without supplying the original instructions and records `_refine_ls_shift/su_max 8.212`. Its nominal formula metadata `H7 B11 Ca0.50 O22 Sr1.50` also differs from the cation-row totals. These are reasons to preserve model provenance, not grounds to choose a preferred final refinement. CIF1/2 use half-formula metadata with Z=4; the journal uses full formula with Z=2, so that convention alone is not a doubled-cell discrepancy.

The central c value in CIF2 agrees with Table 1, but its uncertainty does not. CIF1 cannot resolve the disputed beta uncertainty. Pekov2024 Table 8 repeats Grice2012's Table 1 c and beta values and cites that earlier paper; it is not an independent remeasurement of those cells.

### Cell-volume consistency check

For a monoclinic cell, `V = a × b × c × sin(beta)`:

| 1M source of central metrics | Calculated volume, Å³ | Reported volume, Å³ |
|---|---:|---:|
| CIF2: a 6.7127, b 20.740, c 6.6276, beta 119.21° | 805.3699 | 805.4(2) |
| Printed Table 1: a 6.7127, b 20.704, c 6.6276, beta 119.209° | 803.9798 | 805.4(2) |
| Abstract: same as Table 1 except c 6.6272 | 803.9313 | 805.4(2) |

The CIF's central metrics reproduce its reported volume within the stated volume uncertainty; the printed central metrics do not. This diagnostic identifies another unresolved cell inconsistency and supports asking for the final cell/refinement version. It does not itself establish which printed value should be corrected.
